Credential risk categories (standard terminology):

* **At-rest exposure** (disk, backups, repos)
* **In-memory exposure** (process memory, core dumps, swap)
* **In-transit exposure** (network interception, IPC misuse)
* **Runtime/session exposure** (compromised user session, malware)
* **Privilege escalation exposure** (root, ptrace, /proc access)
* **Supply-chain exposure** (dependencies, compromised binaries)
* **Operational exposure** (logs, debug output, crash reports)
* **Access-control exposure** (over-broad permissions, shared accounts)
